WatermarkRemover-AI

AI-powered watermark removal for images and video.

This is a fork of D-Ogi/WatermarkRemover-AI, maintained by lhadybosxx-design.

Source

github.com/lhadybosxx-design/WatermarkRemover-AI

Running locally

Clone the repo and run the setup script:

git clone https://github.com/lhadybosxx-design/WatermarkRemover-AI.git
cd WatermarkRemover-AI
.\setup.ps1
.\run.bat

Requirements

  • Windows 10/11
  • PowerShell 5+
  • ~5 GB free disk space (models + dependencies)
  • Optional: NVIDIA GPU for faster processing
  • Optional: ffmpeg to preserve audio in video output
